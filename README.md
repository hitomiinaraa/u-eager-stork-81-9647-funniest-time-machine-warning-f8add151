Entry for the [Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) bounty on make.fun.

## The entry

A single warning label for a time machine, printed in the deadpan voice of a
genuine safety notice. It takes the classic time-travel hazard of meeting your
own duplicate and turns it into the joke, saving the punch for the last few
words: if you meet yourself, do not make eye contact, because one of you has
to go, and it is you.

## Run it

```sh
node main.ts
```

It writes the label to `/output/entry.txt` and prints it.
